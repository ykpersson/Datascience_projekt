Maskininlärning från grunden – Binär klassificering på medicinskt dataset
Detta projekt är en del av Data Science‑utbildningen vid EC Utbildning i Göteborg (2026). Syftet är att bygga och analysera binära klassificeringsmodeller matematiskt från grunden, utan att använda färdiga ML‑bibliotek för själva modelleringen.

Datasetet består av syntetiska medicinska variabler (Diabetes Prediction Dataset), vilket lämpar sig väl för att studera sannolikhetsbaserad klassificering.

Innehåll
Projektet omfattar:

Egenimplementerade modeller i Python:

Logistisk regression

K‑Nearest Neighbors

Naive Bayes

Decision Tree

Ett hybridexperiment (Naive Bayes + Decision Tree)

Jämförelse med motsvarande modeller i scikit‑learn

Utvärdering med accuracy, precision, recall, F1 och ROC‑kurvor

Stegvis modellering med olika antal variabler

Syfte
Att förstå och demonstrera hur klassiska ML‑modeller fungerar på en matematisk nivå, samt att jämföra egenimplementerade modeller med etablerade bibliotek.

Tekniker
Python

NumPy / Pandas

Matplotlib / Seaborn

scikit‑learn (endast för jämförelse)
